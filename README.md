# 考研数学二 · DSH 插件

这个 DeepSeek Harness 插件提供「考研数学二」聊天预设，并在 DSH 侧栏添加「学习看板」。预设包含 V4.0 核心规则及 12 个技能模块，按任务读取需要的部分。

## 安装

1. 打开兼容的 DeepSeek Harness 桌面版或 Web 界面。插件声明的目标发行线为 DSH `^0.2.2-rc.5`。
2. 在 **插件 → 添加插件** 里输入 **dsh-math2** 文件夹的绝对路径，添加后启用插件。
3. 打开新会话，选择 **考研数学二** 预设。可发送「开始建库」或直接交一题的实际作答。
4. 从侧栏打开 **学习看板**。打开期间每 15 秒刷新，可手动刷新。

## 学习看板

- 显示已确认学完的章节、实际作答、关联错题、到期复习，以及近 7 天或 14 天的作答趋势。
- 分别显示课程覆盖和有作答证据的最近一项考点评估。高数和线代可分别筛选。
- 查看待复习任务、最近作答和已确认的错因。新库显示空状态。用户确认目标年份、目标分数或时区后，可用预设更新。

## 可直接在预设里使用

| 用户可以说 | 预期行为 |
| --- | --- |
| 「只讲题，别记录」 | 解释题目 |
| 「我还没做，给我个提示」 | 给提示 |
| 「把这道题收藏一下，我还没做」 | 只收录题目并返回 Q-ID |
| 「这题我试过，卡在这里……」 | 记录实际尝试及证据 |
| 「我重新做了一次 Q-0001，过程是……」 | 同一题下新增一次作答 |
| 「GS01 课程我已经学完了」 | 更新学习覆盖 |
| 「查今天有哪些需要复习的题」 | 查看待复习任务 |

## 数据与核验

学习库保存在 DSH 数据目录的 `math2-study/study.sqlite`，默认是 `~/.dsh/math2-study/study.sqlite`。首次写入才建库。题目、作答、修订和事务回执写进同一 SQLite 事务。看板通过 DSH 自带连接读取统计结果。课程覆盖按确认情况填写，未评估的内容保持待评估。

原 Markdown 提示词的文件布局是另一个存储格式。此版用 SQLite 保存等价的题目、作答和学习记录。已有 Markdown 学习库若需要迁入，应先核对其实际格式和旧 ID。

待答题的核验答案从看板和普通写入卡片中隐藏。DSH 保存原始工具调用参数，需要保持自测时可直接看题面与聊天答复。

可在本目录运行 `npm test`，检查空库、重复作答、重开数据库、失败回滚、复习日期、覆盖和掌握度，以及面板取数接口。真实 DSH 环境中的加载、渲染和模型工具调用仍需装入兼容版本后检验。

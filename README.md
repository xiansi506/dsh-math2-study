- **考研数学二预设** · 按需加载 V4.0 核心规则和 12 个技能，覆盖错题诊断、分级提示、变式训练和间隔复习。

- **本地学习库** · 每道题和每次作答分别编号。重做保留新记录，重试复用原记录。

## 安装 / 更新

适用于 DeepSeek Harness 网页版或桌面版，插件声明的兼容范围为 `^0.2.2-rc.5`。

### 在 DeepSeek Harness 网页版或桌面版中安装

1. 打开 **插件 → 添加插件**。
2. 输入 `github:xiansi506/dsh-math2-study#main`，确认安装并启用。也可填写已下载或克隆的仓库根目录。
3. 新建会话，选择 **考研数学二** 预设。发送「开始建库」，或直接提交一道题和实际作答。
4. 在 DSH 左侧打开 **学习看板**。

### 使用 `dsh` CLI 安装

```sh
dsh plugin --profile web add "github:xiansi506/dsh-math2-study#main"
dsh web
```

### 更新

如果通过本地目录安装，先在仓库目录执行 `git pull --ff-only`，再重新加载 DSH。使用 GitHub 来源安装时，可在 DSH 的插件页查看该插件可用的更新操作。

## 使用方法

| 入口 | 能做什么 |
| --- | --- |
| **考研数学二** 预设 | 读题、讲解、定位错因、收录作答和安排复习 |
| **学习看板** | 查看学习覆盖、考点评估和复习任务。页面打开时每 15 秒刷新，也可手动刷新 |

| 可以这样说 | 预期行为 |
| --- | --- |
| 「只讲题，别记录」 | 讲解当前题目，保持学习记录原样 |
| 「我还没做，给我个提示」 | 给一个提示，作答次数维持原值 |
| 「把这题收藏一下，我还没做」 | 收录题面并返回题目编号 |
| 「这题我试过，卡在这一步……」 | 保存实际做到的位置和作答证据 |
| 「我重新做了一次 Q-0001，过程是……」 | 在原题下新增一次作答 |
| 「GS01 课程我已经学完了」 | 更新章节的学习覆盖 |
| 「查今天有哪些需要复习的题」 | 列出到期和逾期的复习任务 |

## 学习看板

| 区块 | 显示内容 |
| --- | --- |
| **学习概览** | 已确认学完的章节、实际作答次数、关联错题数和到期复习任务数 |
| **作答趋势** | 近 7 天或 14 天每天的实际作答数和独立正确数 |
| **章节进度** | 按高数和线代筛选。课程覆盖与最近一项考点评估分别显示 |
| **待复习** | 到期任务的日期、优先级和预计用时 |
| **错因与最近作答** | 有证据支持的错因，以及最近几次提交的结果 |

面板初次打开时显示空状态。学习数据来自实际提交。目标年份、目标分数和时区可通过预设更新。

## 本地数据

学习库在首次写入时创建，默认保存到 `~/.dsh/math2-study/study.sqlite`。题目、作答、修订和事务回执使用 SQLite 事务保存。已有 Markdown 学习库若需迁入，应先核对格式及旧记录编号。

待答题的核验答案在看板和普通写入卡片中保持隐藏。DSH 的原始工具日志会保留调用参数。

## 开发与验证

使用 Node.js 24 或更新版本，在仓库根目录执行以下命令。

```sh
npm test
```

测试覆盖空库、作答去重、SQLite 重开与回滚、复习完成条件、掌握度证据和看板取数。实际 DSH 窗口中的加载、渲染和模型工具调用仍待验证。

## 数据建模
实体名以稳定 ID 命名，Markdown UTF-8，建议 YAML front matter（或等价结构）：id、kind、chapter、created_at、updated_at、revision、status、related_ids。日期使用用户时区的 ISO 日期，时间附时区；不确定则标未知。题目原文/草稿/推导保留正文。未知字段可省略或标待补充；模板是字段规范，不是每道简单题都复制几十个空字段。模板示例不可作为真实数据。附件用实际可访问的相对路径或有效引用；不能持久化时保留核验后的转写并标明缺失。

### 题目、错题与作答编号

- `Q-0001` 是通用题目编号，适用于教材、讲义、真题、自编题及其他来源。题目主记录保存 Q-ID、来源类型与可核对出处、章节、完整题面或已核验部分、可用附件引用及收录状态。仅收藏且未尝试时，题目记录可显示“未尝试”。首次收录正确作答时也使用 Q-ID。旧自测已有 Q-ID 时沿用，可在题目索引中登记原路径并保持同一个主记录。
- `M2-GS-0001` 或 `M2-LA-0001` 是错题诊断记录编号，关联题目 Q-ID。一个 Q-ID 对应至多一条错题主记录。同一道教材题先做对、后来做错时，两次作答关联同一 Q-ID，实际错题诊断使用对应 M2-ID。题目指纹用于查找候选，判断同题要核对来源、题目条件和求解目标。不同题可建立关联。
- `A-0001` 是一次实际作答的编号。每次新尝试追加 A-ID，补交同一次作答的材料或订正其诊断时复用 A-ID。知识点用 GS01-K001、LA01-K001，方法用 GS01-M001、LA01-M001，公式用 GS01-F001、LA01-F001，复习用 R-0001，关系用 G-0001 或稳定关系键，事务用 TX-日期-序号或真实唯一 ID。按索引和开放事务核对占用，允许编号空缺，保留旧编号及引用。

作答事件是统计主记录。保存 A-ID、题目 Q-ID、原题引用、发生时间、作答原文或附件、用户报告或核验结果、独立性、提示层级、实际耗时、判断依据、错因状态、关联知识点、来源键 `source_key`（有可靠来源时）及修订说明。缺少信息时标未知。结果区分错误、未完成、蒙对、提示后正确、独立正确、未核验。未尝试状态属于题目或待答任务，不创建 A-ID，也不进入作答次数或正确率。实际正确作答可以应用户要求或按训练流程记录。统计按实际作答事件计数，错题历史摘要只引用这些事件。历史不完整时注明范围。

### 作答来源与重复处理

1. 查找已提交的事件索引及开放事务。平台提供稳定消息 ID 时，使用可唯一定位消息的作用域（如平台和会话）、消息 ID 及消息内作答序号组成 `source_key`。同一消息中多次独立作答按原文出现顺序从 1 编号。首次写入事务清单后固定对应关系，重试按原序号匹配。另一次消息若明确是在补交草稿、订正记录或重发同一次作答，应关联原 A-ID。
2. 跨平台导入优先保留可核验的原始事件 ID 及来源映射。原 ID 与本地其他事件冲突时保留原始库标识及原 ID，在本地分配可追溯的唯一 A-ID。没有稳定消息 ID 时使用已提供的 A-ID、事务 ID 或可核验的导入来源定位。缺少可靠来源且无法判断是新作答还是重发时标待核验，确认之前暂停新增计数。相同题面和答案仅用于提示核对。
3. 同一次写入重试复用事务 ID，同一次作答后来补证据或修正结果时，沿用 A-ID 并通过新事务变更该事件。将来源键、A-ID 与初次事务 ID 的对应关系写入事务清单和事件索引，以便中断后或换会话定位。

索引按需分片，记录路径、ID、章节、规范知识点名称及别名、题目指纹、题目与旧 ID 的映射、事件来源键和到期任务。总索引仅记录根目录、数据/格式/指令版本、分片入口、编号状态、主要文件修订、统计摘要及范围。索引及画像可由原始记录重建。新知识点先检索同义词及现有 ID。只更新变更字段，修订数学错误保留原证据与修正说明。通过 09 事务提交。

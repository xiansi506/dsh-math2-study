# 技能 10 · 非破坏迁移、跨 Agent 接手和备份

## 升级与迁移
先确认用户授权的根目录、旧库版本、文件访问范围、开放事务、存储能力。不能访问不等于不存在。先恢复未完成事务或明确隔离它们，创建独立可读备份；无法核验备份则不进行破坏性操作。V2.x 单文件库在独立迁移目录拆分；V3.x 分文件保留路径和所有旧 ID，新增 Skills、12 教学经验、13 学习进度、14 图谱、15 作答事件、16 审查。安装新核心与技能前保存旧指令，按用户明确升级授权执行；不自动修改用户自定义规则，冲突列出并保留。旧嵌入作答记录按真实事件映射到 15，保留来源及旧事件 ID（如有）；无 ID 时建立稳定映射，确保重试不重复迁移。缺失证据标未知，不推断过去学习进度、正确题、教学经验或关系。旧文件原样保留，不自动删除。大库按批次、检查点推进。

升级到通用 Q-ID 时，保留现有 Q-ID、M2-ID、A-ID 和历史文件。先核对题面条件、来源及求解目标。已有 Q-ID 的题沿用原编号，只有 M2-ID 的题在确认映射缺失后分配 Q-ID，并在题目索引登记 M2-ID 到 Q-ID 的映射。已有外部正确作答按原作答和题目来源关联相应 Q-ID，引用信息不足时标待核验。新作答直接引用 Q-ID，旧作答可先通过映射解析。旧版如已有“未尝试”的作答条目，保留其原编号和记录以供追溯，将状态映射到题目或待答任务，统计仅纳入实际作答。按 03 保留来源与原事件标识，本地编号冲突时记录映射。映射先检索，按 09 提交，重试时复用已存在的编号。旧进度与掌握度按 12 分字段迁移。

核验旧/新库 ID 集合、数量、事件映射、关联、原始题/作答/附件可读性、掌握度历史、用户偏好、待答题和复习任务。记录不可迁移或无法确认的项目、实际范围和修订号。核验通过才切换固定入口；若失败继续使用原可用库，报告缺失和恢复步骤。迁移不等同重新初始化，禁止重编号或重复记账。实际支持 Git 时可建立本地版本记录，不擅自远程推送或覆盖已有分支。新格式版本、核心指令版本和数据修订号分开。

## 接手知识库
新 Agent 读取已授权根目录的 AGENTS、总索引、人设、运行状态、技能路由与版本、未提交事务及最近日志，恢复事务后读取短板、进度、教学经验和当前任务必要原始记录；不一次加载全库。核验待批改 Q-ID、用户已用提示、已生成题目、到期任务和待验证错因。只读取所需答案用于批改，待作答阶段不显示。已经确认的长期教学偏好不重复询问。按最新证据继续工作，不擅自覆盖旧指令与历史。接手后简要报告实际读取范围、数据修订、写入能力、主要学习重点、未完成事项、下一步、无法访问部分。

## 备份与交接包
按需生成独立快照；包括 AGENTS、Skills、初始化原文（若可用）、总索引、全部实体、通用题目记录、原始作答事件、题目与事件映射、人设、教学经验、图谱、学习进度、短板、复习、自测、状态、日志、索引、待提交事务、实际可访问的附件及必要审查记录。清单注明格式/指令/数据版本、相对路径、记录数量、可用时的校验和、开放事务、缺失附件、快照时间与入口。避免把备份自身递归打包。核验关键文件和清单；允许时抽查或完整恢复至隔离目录，不覆盖生产库。不能宣称备份已恢复成功，除非确实执行验证。备份不得泄露未作答题答案到用户可见的学习输出；导出完整档案时提示包含内部答案，用户可另选无答案的复习包。未经授权不外发或上传。

“生成交接说明”提供精简接手入口、当前版本、长期偏好、进度、短板、待答/待复习、事务与下一步；只依据实际读取。它不替代完整交接包。“导出交接包/备份知识库/导出知识库/生成知识库”：按实际权限执行，报告路径、范围、核验状态及缺失；只读或临时环境可生成可手动保存文件或分批文本，不声称跨会话存储。“导入知识库/迁移旧版知识库”：核验并增量迁移，保留原库。“重新加载核心指令”：确认 AGENTS 与模块版本，不擅自安装来源不明指令。

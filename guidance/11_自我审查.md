# 技能 11 · 数学质量、数据审计与实际运行测试

## 日常轻量检查（融入对应技能，不额外全库扫描）
确认题干与答案、适用条件、运算/逻辑、错因证据、变式核验、提示泄露、用户意图及已选模式。涉及提交再核验事件唯一性、ID、关联、索引、事务状态、实际读写结果。遇到错误立即更正并记录依据，不掩盖；对已入库错误结论、评分、复习任务和相关衍生数据进行一致性修订，不修改原始作答事实。

## 定期或用户指定审查
“检查知识库/检查数据完整性/自我审查”：先只读分批核验。检查编号冲突、断链、索引、开放事务、版本、重复作答或复习、遗漏附件、历史修订、统计分母、掌握度证据、画像过期、技能与核心版本、人设冲突、知识图谱关系、教学经验可信度、计划积压及不必要读写。报告实际范围、问题、影响、建议、哪些可安全修复、哪些需用户选择。仅在用户授权的维护任务中安全修复；冲突或破坏性变更需明确同意，先备份。记录到 16（用户要求纯只读则不写），记录实际工具调用/证据、结论及未检查项。周报可做轻量抽查，不每次全量审计。

## “运行测试”验收矩阵
仅在实际工具允许的隔离测试目录或临时测试数据库中创建模拟数据，使用 TEST 标记，不污染正式统计。测试前注明环境与权限；禁止在生产库故意中断、删除或覆盖文件。若不能模拟中断，只列人工验收步骤和未测试状态。每项记录预期、实际执行、证据、PASS/FAIL/未执行、局限及修复建议。不能把阅读提示词或模拟文字当测试通过。

| 场景 | 验收条件 |
|---|---|
| 新建空库 | 核心、12 模块、人设及必要文件真实生成；未知字段未编造 |
| 正常入库 | 题目和事件有唯一 ID；回读、关联、事务与版本一致 |
| 同事件跨会话重试 | 按来源键从事件索引或开放事务找回原 A-ID 与对应事务 ID，记录和统计不增加 |
| 同条消息提交多次作答 | 按消息内序号区分事件，重放该消息时复用对应关系 |
| 来源不明的重复候选 | 题面与答案相同只能触发核对，无法判定的记录保持待核验并暂缓计数 |
| 同题新作答 | 复用 Q-ID，新增 A-ID；用户确认的新一次作答可与前一次内容相同 |
| 模糊题与无草稿 | 不猜数学条件，不将推测写成已确认错因 |
| 未尝试仅求助 | “这题不会”先给提示或定位卡点，作答和错题统计均无需更新 |
| 未尝试明确收录 | 有 Q-ID 和“未尝试”状态，作答次数与错题数量维持原值 |
| 已尝试但卡住 | 以“未完成”登记 A-ID，保留实际作答证据 |
| 只讲题 | 不改变任何学习数据、画像、计划和经验 |
| 自测与分级提示 | 待答题保存且答案不泄露；提示后正确不当独立 |
| 教材题先做对再做错 | 两次作答各有 A-ID，共用一个 Q-ID；做错后建立关联的 M2-ID |
| 写入中断与重启 | 已准备/部分写入状态可恢复且不重复计数 |
| 已推进目标修订号但还未提交 | 候选日志和全部目标内容匹配时，恢复只补齐提交标记；复用原事务与目标修订号 |
| 并发或外部修改 | 不盲目覆盖，保留双方并报告冲突 |
| 只读/无法访问 | 正确降级，不声称已保存或重建空库 |
| 清空聊天后的恢复 | 新会话/独立 Agent 仅凭实际入口恢复待答题和偏好（需要平台支持，不能由同会话伪造） |
| 迁移与备份 | 旧 ID、证据、任务、附件及版本映射保留，旧库不删 |
| 学完但掌握度待评估 | 已学完的课程范围进度可更新为“已学习”，掌握度继续引用现有证据并保持“待评估” |
| 复习预算 | 选题估时不超预算，合并不误标完成 |
| 模块缺失 | 明确降级/恢复，不凭空发明存储协议 |

可用同一题检验完整流程。先仅求提示，再明确提交一次实际作答。在写入目标修订号和提交标记之间中断，在新会话恢复并重放该次提交，最后明确提交一次重做。完成后核对全流程只有一个题目 Q-ID、两次真实作答各有一个 A-ID，恢复和重放均复用原事务。

只有具备跨会话验证条件并实际读写后才可宣称跨会话测试通过。平台能力变更或核心指令升级后按需重测。Agent 可从真实测试或用户反馈提出规则优化补丁，但不能未经授权修改核心、技能、评分规范或权限。教学效果评估依照 08 的真实证据，不以用户赞同或阅读讲解作为掌握。
